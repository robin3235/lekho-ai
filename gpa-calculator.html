How to Calculate GPA in Bangladesh Universities

বাংলাদেশের বিশ্ববিদ্যালয়ে GPA কীভাবে হিসাব করবেন

GPA (Grade Point Average) হিসাব করা হয় প্রতিটি কোর্সের ক্রেডিট এবং গ্রেড পয়েন্ট গুণ করে, সবগুলো যোগ করে এবং মোট ক্রেডিট দিয়ে ভাগ করে।

সূত্র: GPA = Σ (ক্রেডিট × গ্রেড পয়েন্ট) / মোট ক্রেডিট

⚠️ Common Mistakes Students Make

  • Taking too many difficult courses in one semester
  • Ignoring attendance and class performance marks
  • Not converting old grades properly when calculating CGPA
  • Forgetting to include all semesters in CGPA calculation
  • Not understanding the difference between 4.0 and 4.0+ scale

❓ Frequently Asked Questions

Q: Which grading system should I choose?
A: Public universities (BUET, DU, RUET etc.) → 4.0 Scale
Private universities (NSU, BRAC, AIUB, EWU) → 4.0 Scale (Plus)

Q: Does this calculator support my university?
A: Yes. It supports almost all Bangladeshi universities including BUET, DU, NSU, BRAC, AIUB, EWU, DIU, and more.

Q: How is First Class / Second Class decided?
A: CGPA 3.00+ = First Class, 2.25–2.99 = Second Class, 1.65–2.24 = Third Class.
